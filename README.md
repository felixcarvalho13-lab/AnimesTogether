## Como atualizar

1. Extraia o arquivo ZIP.
2. Substitua no repositório:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Abra `index.html` e teste.
4. No GitHub Desktop:
   - Summary: `Sprint 3 - identidade visual e home`
   - Commit to main
   - Push origin
